MUSH watches silage ferment at Pagi Farm

Silage fermentation happens inside sealed drums, invisible until the batch spoils. MUSH fixes that: ESP32 gateways report DS18B20 temperature, humidity, pressure, MQ-135 gas, and load-cell weight. One API stores it all, a sidecar service forecasts it, and a dashboard plots it.

MUSH Server, the central API

adonisjs, typescript, prisma, postgresql, docker, zod

  • I built the REST API that ingests telemetry from ESP32 gateways and validates every payload with Zod.
  • It rolls readings into hourly and daily aggregations, and provisions a drum record automatically when an unknown device ID shows up.
  • When the ML service is down, the API answers 503 instead of failing silently.

MUSH ML, forecasting sidecar

python, fastapi, scikit-learn, pydantic, pytest

Multi-node RF433 telemetry and PCB hardware

The problem: raw sensor signals drift and pick up noise across distributed nodes. Stable readings need conditioning in hardware, not just filtering in code.

  • I programmed C++ firmware for 4 LGT8F32P Nano-class sensor nodes and an Arduino Mega master board to acquire multi-point sensor data and transmit it wirelessly over RF433 modules.
  • I designed custom analog sensor-conditioning schematics and PCB layouts in KiCad to stabilize signal acquisition across the distributed nodes.
